# Wireframes — Viola's Kitchen

Low-fidelity wireframes for the five key views, addressing the Phase 1 feedback that UI/UX layouts were missing.

## 1. Recipe Index (Home) — `wireframes/wireframe-1-home.png`
Landing page. Header with logo + nav, category filter pills, and a responsive grid of recipe cards (image, category badge, title, prep time). Matches `views/index.ejs`.

## 2. Recipe Detail — `wireframes/wireframe-2-recipe-detail.png`
Full recipe view: title, badge, meta line, hero image, a two-column ingredients/instructions layout, and a comments section with an inline post form. Matches `views/recipe-detail.ejs`.

## 3. Admin Login — `wireframes/wireframe-3-admin-login.png`
Simple centered form (username, password, submit). Matches `views/admin/login.ejs`.

## 4. Admin Dashboard — `wireframes/wireframe-4-admin-dashboard.png`
Table of all recipes with Edit/Delete actions per row, plus a "+ New Recipe" button and Log out. Matches `views/admin/dashboard.ejs`.

## 5. New / Edit Recipe Form — `wireframes/wireframe-5-recipe-form.png`
Shared form for creating and editing a recipe: title, category dropdown, prep time, optional image URL, and multi-line ingredients/instructions fields. Matches `views/admin/recipe-form.ejs`.
